# AIncident — from incident reporting to a commercial SaaS sale

[Read the case study](https://sfskhalsa101.github.io/hari-simran-khalsa-portfolio/projects/aincident/)

AIncident was an AI-powered incident-reporting SaaS product built and deployed by Hari Simran Khalsa through Security Flaw Solutions and sold through Flippa for **$4,995**.

## User and decision
Retail incident-reporting teams need to document an event, review a clear narrative, and share the resulting report.

## Delivered workflow
- Incident reporting with role-based access.
- GPT-generated summaries.
- PDF report export.
- Stripe subscription billing.

## Responsibility
Founder and lead developer: requirements, development, deployment, and commercialization. The published stack includes Python, FastAPI, PostgreSQL, and Streamlit.

## Outcome
The original listing shows one active subscriber and $29 MRR. The sale screenshot shows the $4,995 sale. These commercial outcomes are distinct from operational efficiency metrics.

## Repository scope
This directory contains the case-study page and screenshots. The sold application source is not distributed here. Development later added to AIncident_V1 is separate from the original sold product.
