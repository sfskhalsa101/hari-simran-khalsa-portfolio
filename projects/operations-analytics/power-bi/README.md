# ShiftLens Power BI source project
Open ShiftLens.pbip in Power BI Desktop with project / enhanced report format support enabled. Refresh to load the embedded 84 fictional rows. No file paths or external data connections are needed. Model includes nine DAX measures; report includes four cards, an area slicer, utilization columns, daily productivity lines, and an area comparison table. CSV, SQL, M import and expected results are available alongside this download on the portfolio.

Report JSON is checked against Microsoft public schemas. Desktop open, refresh and visual rendering have not been tested on Windows. Date is ISO text for ordered daily categories; area/date filtering remains available. Targets and outcomes are fictional, not employer operating standards or achieved savings.
